# Modern Recruitment — نسخة Netlify + Nodemailer + Blobs

موقع عربي RTL لمكتب إلحاق العمالة بالخارج، بنفس هوية Modern Recruitment، مع لوحة أدمن `/admin/` وإدارة إعلانات الوظائف وطلبات المتقدمين والشركات وإشعارات بريد Gmail.

## قبل البداية

- هذه **نسخة كاملة من الملفات**، وليست موقعًا منشورًا على الإنترنت. **لم يتم ربط حسابك أو اختبار إرسال Gmail على Netlify** بعد؛ يلزمك ضبط متغيرات البيئة ونشر المشروع كاملًا.
- اسم «مسار الخليج» والوظائف التجريبية هي أمثلة تصميم فقط وليست بيانات مكتب حقيقي. *الوظائف التجريبية لا تظهر للزوار على Netlify*، لكنها تظهر عند فتح ملف HTML مباشرة من الكمبيوتر في وضع المعاينة.
- **لا تضع كلمة مرور الأدمن أو Gmail في `site-config.json` أو `index.html` أو GitHub**. ملف `public/site-config.json` للإعدادات غير السرية الأولية فقط. تعديلات الأدمن الحقيقية تُحفظ في Netlify Blobs.
- لا توجد قاعدة بيانات Supabase، ولا تحتاج شراء سيرفر. تتطبق حدود Netlify المجانية وحدود Gmail.

## نشر الموقع — الطريقة الموصى بها (بدون تثبيت Node على جهازك)

1. فك الضغط عن الملف.
2. افتح GitHub وأنشئ مستودعًا **خاصًا أو عامًا بدون أي أسرار**. ارفع محتويات مجلد المشروع الرئيسي: `public/` و`netlify/` و`scripts/` و`package.json` و`netlify.toml` وREADME؛ **لا ترفع ZIP كما هو كموقع ثابت**.
3. ادخل [app.netlify.com](https://app.netlify.com/) ثم **Add new project → Import an existing project → GitHub**. اختر المستودع.
4. Netlify يقرأ إعدادات `netlify.toml`: **Build command** `npm run build`، **Publish directory** `public`، **Functions directory** `netlify/functions`.
5. قبل استخدام الموقع كخدمة حقيقية، افتح **Project configuration → Environment variables** وأضف المتغيرات بالجدول التالي ضمن سياق Functions (أو جميع السياقات إن تعذر تحديده) وفعّل `Encrypt` / وضع الحماية للمتغيرات السرية إن ظهر.
6. قم بعمل **Trigger deploy → Deploy site** بعد إضافة المتغيرات. اختبر الموقع الرئيسي ثم `/admin/`.

> واجهة Netlify قد تتغير أسماء أزرارها؛ المهم هو الربط مع مستودع Git كامل كي تُبنى وظائف السيرفر وتُثبّت المكتبات من `package.json`. لا ترفع مجلد `public/` وحده عبر Netlify Drop: ذلك قد ينشر HTML فقط دون الوظائف الخلفية.

## متغيرات البيئة المطلوبة

| المتغير | مثال / المطلوب |
|---|---|
| `ADMIN_USERNAME` | `admin` أو اسم تختاره |
| `ADMIN_PASSWORD` | **كلمة مرور قوية وفريدة ≥14 حرفًا**، محفوظة في Netlify فقط |
| `SESSION_SECRET` | قيمة عشوائية سرية بطول **32 حرفًا أو أكثر**؛ لا تستخدم المثال هنا |
| `SMTP_USER` | البريد الذي سيرسل منه Gmail الإشعارات (`youroffice@gmail.com`) |
| `SMTP_PASS` | **Google App Password** مكونة من 16 حرفًا، وليست كلمة مرور Gmail الرئيسية |
| `NOTIFICATION_EMAIL` | البريد المستلم للإشعارات ويمكن أن يساوي `SMTP_USER` |

- الثلاثة الأولى لازمة لتفعيل تسجيل الدخول واستقبال الطلبات. الثلاثة الخاصة بـ Gmail لازمة فقط لإرسال الإيميل. **لو إعدادات البريد ناقصة أو حصل فشل SMTP، تُحفَظ الطلبات في Netlify Blobs وتظهر للأدمن بدون رسالة بريد**.
- للحصول على Google App Password يجب عادةً تفعيل **التحقق بخطوتين** في Google ثم زيارة [myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords). قد لا يتاح لبعض الحسابات.
- خيار أمان إضافي: استخدم `ADMIN_PASSWORD_HASH` بدل `ADMIN_PASSWORD`: شغّل `npm run hash-password` على جهاز لديه Node، وانسخ `ADMIN_PASSWORD_HASH` و`SESSION_SECRET` الناتجين إلى Netlify. إذا اجتمع المتغيران، يأخذ `ADMIN_PASSWORD_HASH` الأولوية. لا تُرسِل كلمة مرور الأدمن أو App Password لأي شخص ضمن المحادثة.
- لن تظهر أسرار Netlify Functions لزوار الموقع؛ **لا تضفها إلى ملفات `public/`**.

## الاستخدام

- الموقع العام: `https://your-site.netlify.app/`
- لوحة الإدارة: `https://your-site.netlify.app/admin/`
- أدخل اسم المستخدم وكلمة المرور من متغيرات Netlify.
- من «الهوية والشعار» غيّر الاسم أو الشعار. من «الهيرو والمحتوى» غيّر العنوان/الوصف والصورة. من «إدارة الوظائف» أضف مسودات أو وظائف منشورة، ثم «الطلبات» لمراجعة طلبات الباحثين والشركات وتصدير CSV.
- استمارة المتقدم لا ترفع CV حاليًا، حرصًا على عدم جمع ملفات شخصية حساسة بلا ضوابط إضافية؛ يمكن إضافتها لاحقًا في مخزن خاص مع سياسة احتفاظ.
- **عند فتح `public/index.html` مباشرة كملف**: تشتغل نسخة عرض محلية مبسّطة، لكن الطلبات والتعديلات تكون **على نفس الجهاز فقط**، بدون أي بريد Gmail أو مزامنة.

## تفاصيل تقنية

- Frontend: HTML/CSS/JavaScript + خطوط Google Fonts + صور مرجعية خارجية وبديل SVG محلي؛ responsive على الهواتف والأجهزة اللوحية والكمبيوتر.
- Backend: وظائف Netlify داخل `netlify/functions/*.mjs`؛ `@netlify/blobs` للتخزين الدائم على مستوى الموقع.
- لا تخرج كلمات مرور Gmail أو جلسات دخول الأدمن إلى الواجهة. جلسة الأدمن تُخزن في Cookie موقعة **HttpOnly + Secure + SameSite=Strict** وتنتهي بعد ثماني ساعات.
- يتم التحقق من صلاحيات الأدمن في السيرفر لكل عملية إضافة/حذف/رفع صورة/قراءة الطلبات؛ صفحة `/admin/` نفسها علنية لكنها لا تمنح صلاحيات دون تسجيل دخول.
- رفع صور JPG/PNG/WebP فقط وبحد أقصى 3MB بعد التحقق من نوع المحتوى وترويسة الملف.
- Netlify Blobs يحفظ كل وظيفة وطلب بمفتاح مستقل لتجنب ضياع الطلبات المتزامنة عند الكتابة على مصفوفة واحدة. طلبات المتقدمين خاصة ولا تُرجع للزوار.
- هناك honeypot وحد تقريبي **5 طلبات لكل عنوان IP في الساعة** لمنع إساءة الاستخدام، لكنه ليس حماية كاملة ضد البوتات؛ مع الزيادة أضف CAPTCHA/Turnstile واشتراطات احتفاظ بالبيانات.
- إرسال SMTP عبر Nodemailer محدود بحسب شروط Gmail ومراقبته ولا يصلح بالضرورة للإرسال التجاري الكثيف. لا يضمن نجاح الإشعارات تحت كل ظروف Gmail.
- تحديث عنوان الصفحة ووصفها من لوحة الأدمن يغيرهما في المتصفح؛ للحصول على SEO فهرسة كاملة يحتاج توليد HTML/SSR مناسب لمحركات البحث لاحقًا.

## الخصوصية والبيانات

- نموذج الطلبات يجمع بيانات اتصال ومهنة؛ اعرض إشعار خصوصية واضح وحدد مدة احتفاظ متناسبة مع الغرض، ومكّن العملاء من طلب حذف بياناتهم.
- لا تطلب صور جوازات السفر أو ملفات تعريف حساسة عبر نموذج التقديم الأولي.
- ضع **البيانات والتراخيص الحقيقية للمكتب** قبل نشر موقع رسمي؛ لا تستخدم الوظائف التجريبية كإعلانات فعلية.
- موقع Netlify يظل ضمن حدود الخطة المجانية واستهلاك Blobs/Functions وليس مجانيًا بلا حدود.

## بنية المشروع

```text
public/
  index.html                الموقع العام
  admin/index.html          لوحة تحكم وإدارة
  site-config.json          إعدادات أولية عامة — بدون أسرار
  assets/                   CSS/JS/SVG
netlify/functions/
  auth.mjs                  جلسة دخول وإغلاق وخروج
  settings.mjs              حفظ/قراءة إعدادات العلامة والهيرو
  jobs.mjs                  نشر/تعديل/حذف الوظائف
  media.mjs                 رفع واسترجاع شعار/صورة هيرو
  submissions.mjs           حفظ الطلبات وإرسال Nodemailer
netlify/lib/core.mjs        حماية وصلاحيات وأدوات مشتركة
scripts/                    بناء المشروع وأداة هاش كلمة المرور
package.json
netlify.toml
.env.example               أسماء المتغيرات فقط — أمثلة غير صالحة
```

## فحص أولي

يمكنك في جهاز عليه Node: `npm install` ثم `npm run check`، ثم `npx netlify-cli dev` لاختبار الوظائف في بيئة محلية مع Environment Variables معدّة. ملفات المشروع جرى فحص JavaScript syntax الخاص بها، لكن لا يمكن التحقق من إرسال بريد Gmail فعلي أو تزامن Netlify Blobs من دون ربط حساباتك.
